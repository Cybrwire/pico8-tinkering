## Pizza Shop Trials

[Play here | プレイできますよ！](https://www.lexaloffle.com/bbs/?tid=157886)

### Rules
* Build the customers pizza and press DONE.
* Try to finish all the customers before time runs out.
* If you run out of time, you lose.
* Press UNDO to take back one topping.
* Press CLEAR to reset the pizza.

### ゲームのやり方
* お客さんの注文通りにピザを作り、DONEを押します。
* 時間内に注文全部クリアしたら、勝ちです！
* 時間が切れてしまったら、負けです。
* UNDOを押してトッピング一個取り消せます。
* CLEARを押してピザをレセットできます。
